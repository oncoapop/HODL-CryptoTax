## 2024-05-24 - TOCTOU Race Condition in Database Initialization
**Vulnerability:** The SQLite database `cytotax.db` was being initialized without explicit file permissions, and created after checking if it exists using `os.path.exists()` and `os.remove()`, making it vulnerable to a Time-of-Check to Time-of-Use (TOCTOU) race condition where a malicious actor could create the file or symlink in the window between removal and SQLite DB creation.
**Learning:** Default SQLite connections do not strictly control creation permissions or handle TOCTOU safely. The window between `os.remove` and `sqlite3.connect` leaves the file vulnerable to hijacking.
**Prevention:** Always pre-create sensitive database files with strict permissions (e.g., `0o600`) using `os.open` with `os.O_CREAT | os.O_EXCL | os.O_RDWR`. Wrap this in a `try...except FileExistsError` block and explicitly raise an error rather than passing, ensuring the application fails securely and prevents TOCTOU exploits.
