## 2024-09-24 - Secure SQLite Database Creation
**Vulnerability:** The local SQLite database file `cytotax.db` was created without explicitly setting file permissions, and the check-then-create logic (`os.path.exists()` then implicit create via `sqlite3.connect()`) left the system open to Time-of-Check to Time-of-Use (TOCTOU) race conditions. An attacker could theoretically replace the file between check and creation, potentially gaining unauthorized read/write access.
**Learning:** Local database files need strict access controls. Relying on default file creation permissions or library defaults (like SQLite's auto-create) is unsafe for sensitive data like tax and crypto transaction records. TOCTOU vulnerabilities must be actively mitigated in file creation logic.
**Prevention:** Pre-create local database files with strict permissions (e.g., `0o600`) using `os.open(DB_PATH, os.O_CREAT | os.O_EXCL | os.O_RDWR, 0o600)`. When using this to mitigate TOCTOU, wrap the call in a `try...except FileExistsError` block and explicitly raise an error in the except block (never `pass`), failing securely if the file unexpectedly exists.
